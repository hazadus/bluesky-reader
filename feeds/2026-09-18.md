💬 Python Tip #261 (of 365):

Use Python's zoneinfo module when working with time zones. 🧵

>>> from zoneinfo import ZoneInfo
>>> pacific = ZoneInfo("America/Los_Angeles")
>>> meeting = datetime(2027, 3, 13, 9, 0, tzinfo=pacific)
>>> print(meeting)
2027-03-13 09:00:00-08:00

#Python #DailyPythonTip

[Открыть пост](https://bsky.app/profile/trey.io/post/3mvsnghogy627)

**🕒 17:01 👤 @trey.io (Trey Hunner)**
💬 datetime.timezone makes timezone-aware datetimes, but only with a FIXED offset from UTC (no Daylight Saving Time).

ZoneInfo time zones know how to handle DST:

>>> print(meeting + timedelta(days=1))
2027-03-14 09:00:00-07:00

Still 9 AM, but DST started, so the offset is -7 instead of -8.

[Открыть пост](https://bsky.app/profile/trey.io/post/3mvsnghspyg2k)

----
**🕒 17:01 👤 @trey.io (Trey Hunner)**
💬 To see the same moment in a different time zone, use the astimezone method:

>>> print(meeting.astimezone(ZoneInfo("Asia/Tokyo")))
2027-03-14 02:00:00+09:00

To get the current time in a zone, pass it to datetime‍.now:

datetime‍.now(tz=pacific)

On Windows you'll need to "pip install tzdata".

Now that there's an official solution in the standard library (since Python 3.9), zoneinfo is the one I'd recommend reaching for most of the time.
