**🕒 15:02 👤 @trey.io (Trey Hunner)**
💬 Python Tip #298 (of 365):

When creating lots of class instances, save memory with __slots__. 🧵

class Point:
    __slots__ = ("x", "y", "z")

    def __init__(self, x, y, z):
        (self.x, self.y, self.z) = (x, y, z)

#Python #DailyPythonTip

[Открыть пост](https://bsky.app/profile/trey.io/post/3mypi32ektc2h)

----
**🕒 15:02 👤 @trey.io (Trey Hunner)**
💬 Without that __slots__ line, every Point instance would store its attributes in a dictionary:

>>> p = Point(1, 2, 3)
>>> p.__dict__
{'x': 1, 'y': 2, 'z': 3}

Dictionaries are flexible, but a dictionary for each instance takes a bit more memory than something smaller like a list/tuple would.

[Открыть пост](https://bsky.app/profile/trey.io/post/3mypi32i6nx26)

----
**🕒 15:02 👤 @trey.io (Trey Hunner)**
💬 With __slots__, Python allocates fixed spots for only the named attributes: no per-instance dictionary at all.

The trade-offs:

1. You can't add attributes that aren't in __slots__
2. Anything that inspects __dict__ will no longer work with your instances (like the built-in vars() function)

[Открыть пост](https://bsky.app/profile/trey.io/post/3mypi32jomu2t)

----
**🕒 15:02 👤 @trey.io (Trey Hunner)**
💬 For millions of instances of a class, __slots__ is definitely worth it.

But for just a handful of objects, don't bother with __slots__.
