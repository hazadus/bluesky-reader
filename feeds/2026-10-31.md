💬 Python Tip #304 (of 365):

Import the whole module when a name isn't clear. 🧵

Do this:
import random

color = random.choice(colors)

Not this:
from random import choice

color = choice(colors)

#Python #DailyPythonTip

💬 I tend to use "from" imports most because I prefer short and descriptive variable names:

from dataclasses import dataclass

But if there's a name like choice that isn't as clear as random.choice, then I'd recommend importing the whole module for the more descriptive name.
