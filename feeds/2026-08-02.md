💬 Python Tip #213 (of 365):

Replace "or"-chained equality comparisons with a containment check 🧵

Instead of this:

is_vowel = c == "a" or c == "e" or c == "i" or c == "o" or c == "u"

You can write this:

is_vowel = c in ("a", "e", "i", "o", "u")

#Python #DailyPythonTip
