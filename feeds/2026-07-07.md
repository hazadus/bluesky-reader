💬 Python Tip #187 (of 365):

Need to count how many items match a condition? Sum up booleans. 🧵

Booleans are integers in Python. True acts just like 1 and False acts just like 0.

I wouldn't rely on that fact often... BUT there's one specific place where this is very handy.

#Python #DailyPythonTip

[Открыть пост](https://bsky.app/profile/trey.io/post/3mpzp6ms24f27)

----
**🕒 03:50 👤 @trey.io (Trey Hunner)**
💬 The any function check whether AT LEAST ONE item in an iterable matches a condition:

>>> numbers = [4, -1, 8, -3, 0, 6]
>>> any(n > 0 for n in numbers)
True

But any/all can't tell you HOW MANY items match.

To count the number of matches, use sum instead:

>>> sum(n > 0 for n in numbers)
3

[Открыть пост](https://bsky.app/profile/trey.io/post/3mpzp6pcuw32u)

----
**🕒 03:50 👤 @trey.io (Trey Hunner)**
💬 That works because summing up True/False effectively counts the number of True values.

If it feels weird to sum boolean expressions, you COULD convert each boolean to an integer explicitly:

sum(int(n > 0) for n in numbers)

But I actually find this more readable:

sum(n > 0 for n in numbers)

[Открыть пост](https://bsky.app/profile/trey.io/post/3mpzp6pfxqo26)

----
**🕒 03:50 👤 @trey.io (Trey Hunner)**
💬 Note that if you're counting the number of times a SINGLE value occurs, there's an even easier approach:

>>> from operator import countOf
>>> countOf(numbers, 0)
1

That countOf call is equivalent to:

>>> sum(n == 0 for n in numbers)
1

But if you're working with a list, just use the count method.

**🕒 03:50 👤 @trey.io (Trey Hunner)**
💬 So you can count items in an arbitrary iterable with operator.countOf and count conditional matches that AREN'T just equality by combining the sum function with a generator expression.

This is pretty much the ONE context in which I use the integer nature of booleans in Python.

💬 Python Tip #188 (of 365):

To find the first item that matches a condition, combine next with a generator expression. 🧵

The gen expr finds matching items lazily and next() stops when a match is found:

>>> numbers = [4, -1, 8, -3, 0]
>>> next(n for n in numbers if n < 0)
-1

#Python #DailyPythonTip

[Открыть пост](https://bsky.app/profile/trey.io/post/3mq36x5yf5v22)

**🕒 18:04 👤 @trey.io (Trey Hunner)**
💬 What if nothing matches?

>>> next(n for n in numbers if n > 100)
Traceback (most recent call last):
  ...
StopIteration

In that case, a StopIteration exception will be raised.

To avoid that, pass a default value as the second argument to next:

>>> next((n for n in numbers if n > 100), None)
>>>
