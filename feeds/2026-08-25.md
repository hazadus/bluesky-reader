💬 Python Tip #237 (of 365):

Need a read-only attribute? Use a property. 🧵

Properties are read-only by default:

>>> s = Square(4)
>>> s.area
16
>>> s.area = 100
Traceback (most recent call last):
  ...
AttributeError: property 'area' of 'Square' object has no setter

**🕒 18:04 👤 @trey.io (Trey Hunner)**
💬 To make a "regular" attribute read-only, make it a property that reads from an underscore-prefixed attribute:

class Square:
    def __init__(self, length):
        self._length = length

    @property
    def length(self):
        return self._length

Now length can be read but not assigned.

[Открыть пост](https://bsky.app/profile/trey.io/post/3mtwfquibx32h)

**🕒 18:04 👤 @trey.io (Trey Hunner)**
💬 Why the underscore? The property's data has to live somewhere, and that spot can't have the SAME name as the property.

The _length attribute is still reachable, but the underscore marks it as private by convention (see tip #230).
