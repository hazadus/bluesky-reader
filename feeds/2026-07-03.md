💬 Python Tip #184 (of 365):

Always specify the encoding when opening text files. 🧵

If you don't, Python picks a platform-dependent default, and you may read garbled text or get an error.

#Python #DailyPythonTip

**🕒 18:04 👤 @trey.io (Trey Hunner)**
💬 A wrong encoding sometimes results in "mojibake": characters that look like garbled nonsense.

Opening a UTF-8 file as CP-1252 can turn "✨" into "âœ¨":

>>> from pathlib import Path
>>> Path("sparkles.txt").write_text("✨", encoding="utf-8")
>>> Path("sparkles.txt").read_text(encoding="cp1252")
'âœ¨'

[Открыть пост](https://bsky.app/profile/trey.io/post/3mpr523mans2d)

----
**🕒 18:04 👤 @trey.io (Trey Hunner)**
💬 I recommend passing an explicit encoding.

This is fragile (may use cp1252 on Windows):

with open("data.txt") as file:
    text = file.‍read()

This works the same on all systems:

with open("data.txt", encoding="utf-8") as file:
    text = file.‍read()

UTF-8 is right for most files (but not all!)

**🕒 18:04 👤 @trey.io (Trey Hunner)**
💬 This tip (fortunately) has an expiration date!

Python 3.15 will default to UTF-8 everywhere.

So when you eventually drop support for Python 3.14 and below (2030 maybe?), omitting encoding will no longer be a cross-platform hazard.
