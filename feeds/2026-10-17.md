💬 Python Tip #290 (of 365):

Pretty-print data structures with pp. 🧵

>>> from pprint import pp
>>> pp(user)
{'name': 'Trey',
 'languages': ['Python', 'JavaScript'],
 'address': {'city': 'San Diego', 'state': 'CA'}}

#Python #DailyPythonTip

**🕒 18:02 👤 @trey.io (Trey Hunner)**
💬 With print, that dictionary is less readable:

>>> print(user)
{'name': 'Trey', 'languages': ['Python', 'JavaScript'], 'address': {'city': 'San Diego', 'state': 'CA'}}

Pretty-printing is great for data structures that are too long for one line. It's especially helpful for nested data structures.

[Открыть пост](https://bsky.app/profile/trey.io/post/3my3oeljelw2m)

----
**🕒 18:02 👤 @trey.io (Trey Hunner)**
💬 The pprint.pprint function sorts dictionary keys, but pprint.pp keeps them in their original order.

PDB's pp command pretty-prints too (sorting keys, like pprint does):

(Pdb) pp user
{'address': {'city': 'San Diego', 'state': 'CA'},
 'languages': ['Python', 'JavaScript'],
 'name': 'Trey'}

**🕒 18:02 👤 @trey.io (Trey Hunner)**
💬 If, like me, you wish pretty printed output looked like formatted code, try Python 3.15's "expand=True":

>>> pp(user, expand=True)
{
 'name': 'Trey',
 'languages': ['Python', 'JavaScript'],
 'address': {'city': 'San Diego', 'state': 'CA'},
}

That shows the same shape that Black & ruff use.
