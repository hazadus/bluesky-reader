💬 Python Tip #317 (of 365):

For complex substitutions, pass a function to re.sub. 🧵

Python's re.sub performs a regular expression substitution, replacing matches with replacement text.

It'll also take a FUNCTION, which accepts a match object and returns replacement text.

💬 This substitution function guesses a century for each 2-digit year:

DATE_RE = re.compile(r"(\d{2})/(\d{2})/(\d{2})")

def replace_date(match):
    month, day, year = match.groups()
    century = "20" if year < "50" else "19"
    return f"{century}{year}-{month}-{day}"

**🕒 16:02 👤 @trey.io (Trey Hunner)**
💬 >>> DATE_RE.sub(replace_date, "from 09/24/91 to 04/23/16")
'from 1991-09-24 to 2016-04-23'

A replacement string could reorder the date parts, but not choose a century.

Substitutions don't usually need functions, but if you need to do a complex substitution, they can come in handy.
