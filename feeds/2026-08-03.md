💬 Python Tip #214 (of 365):

Use truthiness for integers with caution. 🧵

Sometimes it helps readability but sometimes it can hurt it.

I find:
if hours: ...

More readable than:
if hours > 0: ...

But I find:
if number % 2 != 0: ...

More readable than:
if number % 2: ...

#Python #DailyPythonTip

**🕒 23:38 👤 @trey.io (Trey Hunner)**
💬 Python Tip #215 (of 365):

Know what it means to be a "sequence" in Python. 🧵

A sequence is an ordered collection that:

1. Has a length
2. Can be indexed from "0" up to one less than its length
3. Can be looped over

Lists, strings, and tuples are all sequences.

#Python #DailyPythonTip

[Открыть пост](https://bsky.app/profile/trey.io/post/3ms7o6okhlf27)

----
**🕒 23:38 👤 @trey.io (Trey Hunner)**
💬 Each of these 3 sequences:

>>> fruits = ["apple", "lemon", "pear"]
>>> coordinates = (1, 8, 2)
>>> greeting = "Hi y'all!"

Supports these 3 operations (len, index, iteration):

>>> len(fruits)
3
>>> fruits[0]
'apple'
>>> list(fruits)
['a', 'p', 'p', 'l', 'e']

[Открыть пост](https://bsky.app/profile/trey.io/post/3ms7o6onn4c26)

**🕒 23:38 👤 @trey.io (Trey Hunner)**
💬 Sequences also USUALLY support negative indexing and slicing:

>>> coordinates[-1]
2
>>> greeting[:-1]
"Hi y'all"

And sequences should all have an index method and a count method.

The "in" operator also works on sequences but it's usually slow because (by default) it loops over the sequence.

**🕒 23:38 👤 @trey.io (Trey Hunner)**
💬 All sequences are iterables, but not all iterables are sequences.

For example, sets have a length, but they can't be indexed:

>>> colors = {'red', 'blue', 'yellow'}
>>> colors[0]
TypeError: 'set' object is not subscriptable

Dictionaries can't be indexed either: [...] on a dict does a key lookup.

💬 Why is it helpful to know what a "sequence" is?

1. It's a mental shortcut: "X is a sequence" tells you a handful of things X supports
2. If a function claims to accept a sequence, you need to know what you can pass it
3. If your function works with any sequence (not just lists), document that!
