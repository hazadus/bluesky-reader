💬 Python Tip #246 (of 365):

Measure your test coverage, including BRANCH coverage. 🧵

$ coverage run --branch -m pytest
$ coverage report

Or with the pytest-cov plugin:
$ pytest --cov --cov-branch

#Python #DailyPythonTip

**🕒 03:44 👤 @trey.io (Trey Hunner)**
💬 Code coverage lets you know WHICH lines of code were run by your automated tests.

For Python, coverage‍.py is great for measuring this.

Lines that are missing coverage are NEVER EVEN RUN by your tests. Code that isn't run is code that isn't tested.

[Открыть пост](https://bsky.app/profile/trey.io/post/3muo2frgi2r2a)

----
**🕒 03:44 👤 @trey.io (Trey Hunner)**
💬 By default, coverage‍.py only measures LINE coverage. Say we have this function:

def calculate_total(amounts, apply_tax=True, tax_rate=.10):
    total = sum(amounts)
    if apply_tax:
        total *= (1+tax_rate)
    return round(total, 2)

And a test that only calls it with "apply_tax=True".

[Открыть пост](https://bsky.app/profile/trey.io/post/3muo2frj7pz25)

----
**🕒 03:44 👤 @trey.io (Trey Hunner)**
💬 Every line runs, so we get 100% line coverage:

Name           Stmts   Miss  Cover
----------------------------------
calculate‍.py       5      0   100%

But that "if" condition always evaluated as True in our tests. We never tested what happens when it's False.

[Открыть пост](https://bsky.app/profile/trey.io/post/3muo2frlp7f2u)

----
**🕒 03:44 👤 @trey.io (Trey Hunner)**
💬 If we run coverage with "--branch", we can see the missing code path (the untaken falsey condition):

Name           Stmts   Miss Branch BrPart  Cover
------------------------------------------------
calculate‍.py       5      0      2      1    86%

Every LINE ran, but a BRANCH was missed.

[Открыть пост](https://bsky.app/profile/trey.io/post/3muo2froa3p2l)

----
**🕒 03:44 👤 @trey.io (Trey Hunner)**
💬 Note that code coverage CANNOT tell you whether your tests are ADEQUATE. Coverage can only indicate lines that were never run and branches that were never taken.

It's possible for tax_rate to NEVER be passed to calculate_total by automated tests while maintaining 100% line AND branch coverage.
