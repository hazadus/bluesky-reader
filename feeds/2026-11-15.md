💬 Python Tip #319 (of 365):

Name your regular expression capture groups. 🧵

Capture groups are neat, but it can be confusing figuring out what the group numbers represent:

>>> match = re‍.search(r"(\d{2})/(\d{2})/(\d{4})", "from 12/22/1629")
>>> match[3]
'1629'

#Python #DailyPythonTip

[Открыть пост](https://bsky.app/profile/trey.io/post/3n2ef4qstum2t)

----
**🕒 16:01 👤 @trey.io (Trey Hunner)**
💬 Here's a named capture group instead:

>>> DATE_RE = re.compile(r"(?P\d{2})/(?P\d{2})/(?P\d{4})")
>>> match = DATE_RE‍.search("from 12/22/1629")
>>> match["year"]
'1629'

That "?P" after the opening parenthesis gives a group a name in angle brackets.

[Открыть пост](https://bsky.app/profile/trey.io/post/3n2ef4qynme23)

----
**🕒 16:01 👤 @trey.io (Trey Hunner)**
💬 That syntax is a little weird, but now we can use match["year"] instead of match[3].

The groupdict method gives us a dictionary of the named groups:

>>> match.groupdict()
{'month': '12', 'day': '22', 'year': '1629'}

[Открыть пост](https://bsky.app/profile/trey.io/post/3n2ef4r2ut22m)

----
**🕒 16:01 👤 @trey.io (Trey Hunner)**
💬 A replacement string can refer to a named group with "\g":

>>> DATE_RE.sub(r"\g-\g-\g", "from 12/22/1629 to 11/14/1643")
'from 1629-12-22 to 1643-11-14'

And a substitution function (see tip #317) can use match["year"] instead of relying on the order of the groups.
