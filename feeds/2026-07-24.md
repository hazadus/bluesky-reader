**🕒 18:04 👤 @trey.io (Trey Hunner)**
💬 Python Tip #205 (of 365):

Use statistics.multimode to get the most common items 🧵

Need the most common items in an iterable?

You might be tempted to use collections.Counter.

Consider using statistics.multimode instead.

#Python #DailyPythonTip

[Открыть пост](https://bsky.app/profile/trey.io/post/3mrfwtecomf2s)

----
**🕒 18:04 👤 @trey.io (Trey Hunner)**
💬 Here we're using collections.Counter to find the most common list items:

from collections import Counter
items = [3, 1, 2, 2, 2, 1, 3, 3, 2, 2]
counts = Counter(items)
[(_, top_count)] = counts.most_common(1)
commonest = [
    item
    for item, count in counts.items()
    if count == top_count
]

[Открыть пост](https://bsky.app/profile/trey.io/post/3mrfwtflg6c2e)

**🕒 18:04 👤 @trey.io (Trey Hunner)**
💬 And here we're using statistics.multimode instead:

from statistics import multimode
items = [3, 1, 2, 2, 2, 1, 3, 3, 2, 2]
commonest = multimode(items)

A bit simpler, right?

More in the docs:
https://docs.python.org/3/library/statistics.html#statistics.multimode
