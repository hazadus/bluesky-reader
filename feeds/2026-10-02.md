**🕒 22:01 👤 @trey.io (Trey Hunner)**
💬 Python Tip #275 (of 365):

Pre-fill arguments with functools.partial. 🧵

>>> from functools import partial
>>> hex_to_int = partial(int, base=16)
>>> hex_to_int("CAFE")
51966

This is sometimes called "partially evaluating" a function.

#Python #DailyPythonTip

[Открыть пост](https://bsky.app/profile/trey.io/post/3mwweraoqb52d)

----
**🕒 22:01 👤 @trey.io (Trey Hunner)**
💬 I prefer this:
hex_to_int = partial(int, base=16)

Instead of this:
hex_to_int = lambda s: int(s, base=16)

The partial version is a more specialized tool than "lambda": its only purpose is to call a callable with certain arguments preset.

[Открыть пост](https://bsky.app/profile/trey.io/post/3mwwerarwra2u)

----
**🕒 22:01 👤 @trey.io (Trey Hunner)**
💬 Both positional and keyword arguments can be pre-filled:

debug = partial(print, "DEBUG:", sep=" | ")

partial objects work anywhere a callable is expected: key functions, callbacks, defaultdict factories, etc.

[Открыть пост](https://bsky.app/profile/trey.io/post/3mwweraxrdg2s)

----
**🕒 22:01 👤 @trey.io (Trey Hunner)**
💬 Need to skip a positional argument? Use Placeholder (Python 3.14+):

>>> from functools import Placeholder
>>> remove_dashes = partial(str.replace, Placeholder, "-", "")
>>> remove_dashes("555-867-5309")
'5558675309'

That's handy for functions that don't accept keyword arguments, like str.replace.
