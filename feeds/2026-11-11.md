Split on multiple separators with re.split. 🧵

>>> import re
>>> tags = "python;regex,strings"
>>> re.split(r'[,;]', tags)

**🕒 05:10 👤 @trey.io (Trey Hunner)**
💬 The re.split function can also match optional whitespace around a separator or split on things besides a simple substring:

>>> row = "column 1,column 2, column 3"
>>> re.split(r',\s*', row)
['column 1', 'column 2', 'column 3']

**🕒 05:10 👤 @trey.io (Trey Hunner)**
💬 One gotcha/feature: if your pattern contains a capture group, re.split will INCLUDE the captured separators in the result:

>>> re.split(r'(,|;)', tags)
['python', ';', 'regex', ',', 'strings']

To avoid that, use a non-capturing group "(?:like this)".

**🕒 23:20 👤 @trey.io (Trey Hunner)**
💬 Python Tip #315 (of 365):

Don't reach for random.random. 🧵

Need a random integer? Don't multiply a random float and convert the result. The randint function does that more directly.

Do this:
random.randint(1, 6)

Not this:
int(random.random() * 6) + 1

#Python #DailyPythonTip

[Открыть пост](https://bsky.app/profile/trey.io/post/3n233s2ztgs2a)

----
**🕒 23:20 👤 @trey.io (Trey Hunner)**
💬 In JavaScript, Math.random is the random number generation utility. Need a random integer? Use Math.random. Need a random item from an array? Use Math.random.

Python's random module isn't like that. Instead of one low-level function, random includes specialized tools for different use cases.

[Открыть пост](https://bsky.app/profile/trey.io/post/3n233s3sw4b2z)

----
**🕒 23:20 👤 @trey.io (Trey Hunner)**
💬 So random.random (which returns a random float between 0 and 1) is rarely the one you actually need.

Need a random item from a sequence? That's what random.choice is for (see tip #150). And for multiple items, there's random.choices(colors, k=3).

----
**🕒 23:20 👤 @trey.io (Trey Hunner)**
💬 Need randomness for a token or a password? Use the secrets module (see tip #151).

It's not wrong to use random.random. It's just rarely the right level of abstraction. Nearly every time you need randomness, there's a more specific function that could convey what you mean more clearly.
