💬 Python Tip #190 (of 365):

To remove duplicates while maintaining the original iterable order, use dict.fromkeys. 🧵

A set will remove duplicates, but also lose the original order:

>>> colors = ["red", "green", "blue", "green"]
>>> set(colors)
{'blue', 'green', 'red'}

**🕒 22:45 👤 @trey.io (Trey Hunner)**
💬 Dictionaries can't have duplicate keys AND they maintain insertion order.

So dict.fromkeys is a bit of a cheat:

>>> list(dict.fromkeys(colors))
['red', 'green', 'blue']

Each item in the iterable becomes a key, preserving first-seen order. Wrap it in list to iterate keys and get a list instead.
