**🕒 04:46 👤 @trey.io (Trey Hunner)**
💬 Python Tip #305 (of 365):

Split only as much as you need with maxsplit. 🧵

Do this:
key, value = line.split("=", maxsplit=1)

Not this:
key, *rest = line.split("=")
value = "=".join(rest)

#Python #DailyPythonTip

[Открыть пост](https://bsky.app/profile/trey.io/post/3mzcjejjnu42h)

----
**🕒 04:46 👤 @trey.io (Trey Hunner)**
💬 Calling split without maxsplit breaks when the value contains the separator:

>>> line = "API_KEY=3q2+7w=="
>>> key, value = line.split("=")
Traceback (most recent call last):
  ...
ValueError: too many values to unpack (expected 2, got 4)

[Открыть пост](https://bsky.app/profile/trey.io/post/3mzcjejmkzc2t)

----
**🕒 04:46 👤 @trey.io (Trey Hunner)**
💬 With a maxsplit value, Python will split the string the given number of times:

>>> key, value = line.split("=", maxsplit=1)
>>> value
'3q2+7w=='

This is handy when you only care about the first one or two occurrences of a separator.

[Открыть пост](https://bsky.app/profile/trey.io/post/3mzcjejo2r726)

----
**🕒 04:46 👤 @trey.io (Trey Hunner)**
💬 If it's the last couple occurrences of a separator that you care about, you'll want the string rsplit method instead:

>>> dotted_name = "collections‍.abc.Iterable"
>>> module_name, class_name = dotted_name.rsplit(".", maxsplit=1)
>>> module_name
'collections‍.abc'
