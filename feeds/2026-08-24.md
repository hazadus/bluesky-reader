💬 Python Tip #236 (of 365):

Don't write getter and setter methods in Python. 🧵

If you need to customize what happens when an attribute is accessed or assigned, use a property.

#Python #DailyPythonTip

[Открыть пост](https://bsky.app/profile/trey.io/post/3mtueydfnyz26)

----
**🕒 22:45 👤 @trey.io (Trey Hunner)**
💬 In Java, it's best practice to use getters and setters instead of direct attribute access, in case you ever need to customize them.

In Python, we usually just use attributes directly.

When we DO need to customize attribute access, we make a property. Here's one that rejects negative stock values:

[Открыть пост](https://bsky.app/profile/trey.io/post/3mtueyflfqf2v)

----
**🕒 22:45 👤 @trey.io (Trey Hunner)**
💬 class Item:
    def __init__(self, stock):
        self.stock = stock
    @property
    def stock(self):
        return self._stock
    @stock.setter
    def stock(self, value):
        if value < 0:
            raise ValueError("Stock cannot be negative")
        self._stock = value

[Открыть пост](https://bsky.app/profile/trey.io/post/3mtueyfofue2p)

----
**🕒 22:45 👤 @trey.io (Trey Hunner)**
💬 Every assignment to stock (even the one in __init__) goes through the setter.

But users of this class just see a normal attribute:

>>> item = Item(stock=4)
>>> item.stock -= 1
>>> item.stock
3
>>> item.stock -= 5
Traceback (most recent call last):
  ...
ValueError: Stock cannot be negative
