💬 Python Tip #189 (of 365):

Check for duplicates by converting to a set. 🧵

To check whether your collection contains duplicate items, you can make a set out of it and compare the original collection length to the set length:

>>> len(set(colors)) == len(colors)
False

#Python #DailyPythonTip

**🕒 18:04 👤 @trey.io (Trey Hunner)**
💬 A set can't hold duplicates, so if converting to a set shrinks the length, there were duplicates. Otherwise all items were unique.

One caveat: this only works if each item is hashable (like strings, numbers, and tuples of hashable items).
