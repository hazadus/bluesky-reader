💬 Python Tip #294 (of 365):

Use exceptions to pass error messages to users. 🧵

Catch exceptions with messages users shouldn't see, and raise your own with a message they SHOULD see:

class WeatherError(Exception):
    """Raised when we can't show the user a forecast."""

**🕒 15:04 👤 @trey.io (Trey Hunner)**
💬 Why not print and exit right where the problem was detected?

Because exiting within a random function is messy. Imagine if load_forecast was called more than once, sometimes with data that didn't come from a user.

Raising an exception lets EACH caller decide how to handle the exceptional case.

**🕒 15:04 👤 @trey.io (Trey Hunner)**
💬 Note that at the edge of your program, you'll want to catch JUST your custom exception type.

A bare "except" (or "except Exception") there would also turn bugs in your code into one-line messages for the end user, hiding any traceback you'd want to see when troubleshooting them.
