💬 Python Tip #262 (of 365):

Parse dates with date.strptime. 🧵

In Python 3.14+, the date class got its own strptime class method:

>>> import datetime as dt
>>> dt.date.strptime("2026-08-19", "%Y-%m-%d")
datetime‍.date(2026, 8, 19)

#Python #DailyPythonTip

----
**🕒 17:00 👤 @trey.io (Trey Hunner)**
💬 Before 3.14, strptime only existed on datetime, so you needed to parse a datetime and then extract the date from it:

>>> dt.datetime.strptime("2026-08-19", "%Y-%m-%d").date()
datetime‍.date(2026, 8, 19)

That's still the way to do it if you're on Python 3.13 or below.

[Открыть пост](https://bsky.app/profile/trey.io/post/3mvv5uzejcg24)

----
**🕒 17:00 👤 @trey.io (Trey Hunner)**
💬 3.14 also added strptime to the time class:

>>> dt.time.strptime("14:30", "%H:%M")
datetime.time(14, 30)

So on Python 3.14+, call .strptime() directly on the dt‍.date/dt.time class instead of chaining a .date() or .time() afterward.
