💬 Python Tip #270 (of 365):

Move and copy files with pathlib. 🧵

In Python 3.14, Path objects gained move and copy methods, and copy works on whole directories:

>>> from pathlib import Path
>>> taxes = Path("taxes")
>>> taxes.copy("taxes-backup")
PosixPath('taxes-backup')

#Python #DailyPythonTip

**🕒 23:00 👤 @trey.io (Trey Hunner)**
💬 There are four new methods:

• move(target): move to a new path
• move_into(directory): move into a directory
• copy(target): copy to a new path
• copy_into(directory): copy into a directory

The "*_into" variants save you from manually joining the directory and filename.

**🕒 23:00 👤 @trey.io (Trey Hunner)**
💬 Before 3.14, if you wanted to copy a directory, you had to use shutil:

shutil.copytree(taxes, "taxes-backup")

Path.rename could only move files within one filesystem. The move method works across filesystems.

If you're on 3.14+, I'd use these methods instead of the equivalent shutil functions.
