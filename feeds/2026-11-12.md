💬 Python Tip #316 (of 365):

Time code with time.perf_counter. 🧵

Do this:
from time import perf_counter

start = perf_counter()
process(data)
elapsed = perf_counter() - start

Not this:
from time import time

start = time()
process(data)
elapsed = time() - start

#Python #DailyPythonTip

**🕒 16:32 👤 @trey.io (Trey Hunner)**
💬 time.perf_counter is made for measuring durations: it uses the highest-resolution clock available and only ever moves forward:

>>> import time
>>> time.get_clock_info("time").adjustable
True
>>> time.get_clock_info("perf_counter").adjustable
False

💬 The number time.perf_counter returns means nothing on its own (its starting point is undefined), so only use it to compute the DIFFERENCE between two calls.

Also note that timeit.default_timer is an alias for time.perf_counter.

**🕒 16:32 👤 @trey.io (Trey Hunner)**
💬 Here's a Timer context manager built on it:

from time import perf_counter

class Timer:
    def __enter__(self):
        self.start = perf_counter()
        return self

    def __exit__(self, *args):
        self.elapsed = perf_counter() - self.start
