**🕒 05:26 👤 @trey.io (Trey Hunner)**
💬 Python Tip #311 (of 365):

Make directories with parents and exist_ok. 🧵

Like this:
pathlib.Path("reports/2026").mkdir(parents=True, exist_ok=True)

#Python #DailyPythonTip

[Открыть пост](https://bsky.app/profile/trey.io/post/3mzroepsjn42t)

----
**🕒 05:26 👤 @trey.io (Trey Hunner)**
💬 Without "parents=True", the mkdir method raises an exception when parent directories are missing:

>>> reports = Path("reports/2026")
>>> reports.mkdir()
FileNotFoundError: [Errno 2] No such file or directory: 'reports/2026'

Passing "parents=True" will create missing parent directories.

[Открыть пост](https://bsky.app/profile/trey.io/post/3mzroepwp4725)

----
**🕒 05:26 👤 @trey.io (Trey Hunner)**
💬 And without "exist_ok=True", mkdir raises an exception when the directory already exists:

>>> reports.mkdir(parents=True)
>>> reports.mkdir(parents=True)
FileExistsError: [Errno 17] File exists: 'reports/2026'

Passing "exist_ok=True" silently does nothing if the directory already exists.

[Открыть пост](https://bsky.app/profile/trey.io/post/3mzroepy6xh25)

----
**🕒 05:26 👤 @trey.io (Trey Hunner)**
💬 With both arguments, a mkdir will make parent directories as needed and not complain if the directory already exists.

An exception will still be raised for other issues (like if there's a file at that path).
