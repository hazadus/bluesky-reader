💬 Python Tip #293 (of 365):

Write context managers with contextlib.contextmanager. 🧵

Instead of making a class with __enter__ and __exit__ methods, we can make a context manager out of a function:

#Python #DailyPythonTip

[Открыть пост](https://bsky.app/profile/trey.io/post/3mycvrmvp2326)

----
**🕒 15:03 👤 @trey.io (Trey Hunner)**
💬 @contextmanager
def set_env_var(name, new_value):
    original_value = os.environ.get(name)
    os.environ[name] = new_value
    try:
        yield
    finally:
        if original_value is None:
            del os.environ[name]
        else:
            os.environ[name] = original_value

[Открыть пост](https://bsky.app/profile/trey.io/post/3mycvrmythy2m)

----
**🕒 15:03 👤 @trey.io (Trey Hunner)**
💬 We can use it in a "with" block, like any other context manager:

>>> with set_env_var('USER', 'akin'):
...     print(os.environ['USER'])
...
akin

The code BEFORE the "yield" runs when the "with" block is entered and the code AFTER runs when the block exits.

[Открыть пост](https://bsky.app/profile/trey.io/post/3mycvrn2rxy2m)

----
**🕒 15:03 👤 @trey.io (Trey Hunner)**
💬 The "try"/"finally" makes sure the environment variable is restored even if an exception is raised in the "with" block.

The generator function you decorate must only "yield" one time: that "yield" shouldn't be in a loop and there shouldn't be more than one of them.

[Открыть пост](https://bsky.app/profile/trey.io/post/3mycvrn4o372d)

----
**🕒 15:03 👤 @trey.io (Trey Hunner)**
💬 To customize what your context manager returns to its "with" block, pass a value to the "yield" statement.

The contextmanager decorator is great for SIMPLE context managers. If your __enter__ or __exit__ methods need a lot of logic, using a class might be easier to understand.
