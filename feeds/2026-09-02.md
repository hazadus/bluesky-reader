💬 Python Tip #245 (of 365):

Use approximate comparisons for floating point numbers in your tests. 🧵

As noted back in tip #203, floating point numbers have precision gotchas:

>>> one_two = 0.1 + 0.02
>>> one_two == 0.12
False
>>> one_two
0.12000000000000001

💬 When I need to compare a floating point result in an automated test, I use a tool that asserts its correctness FUZZILY.

Instead of ==, one option is math.isclose:

>>> import math
>>> math.isclose(one_two, 0.12)
True

But in automated tests, there's usually an even more specialized helper.

💬 If you're using unittest, call self.assertAlmostEqual instead of self.assertEqual.

If you're using pytest, I'd use the pytest.approx helper. It returns an object to compare WITH, using ==:

assert one_two == pytest.approx(0.12)
