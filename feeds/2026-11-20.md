**🕒 21:00 👤 @trey.io (Trey Hunner)**
💬 Python Tip #324 (of 365):

Sort a dictionary with dict(sorted(d.items())). 🧵

>>> counts = {"sandwiches": 10, "drinks": 20, "oranges": 7}
>>> dict(sorted(counts.items()))
{'drinks': 20, 'oranges': 7, 'sandwiches': 10}

#Python #DailyPythonTip

[Открыть пост](https://bsky.app/profile/trey.io/post/3n2ri7czv3c2x)

----
**🕒 21:01 👤 @trey.io (Trey Hunner)**
💬 The dictionary items method gives us key-value tuples, sorted makes a sorted list out of them, and dict turns them back into a dictionary.

Tuples sort by their first items first, so this sorts by keys.

Since dictionaries maintain insertion order (see tip #323), the new dictionary stays sorted.

[Открыть пост](https://bsky.app/profile/trey.io/post/3n2ri7diho42l)

----
**🕒 21:01 👤 @trey.io (Trey Hunner)**
💬 To sort by values instead, pass a key function to sorted:

>>> from operator import itemgetter
>>> dict(sorted(counts.items(), key=itemgetter(1)))
{'oranges': 7, 'sandwiches': 10, 'drinks': 20}

itemgetter(1) gets the second item (the value) from each key-value tuple (see tip #148).

[Открыть пост](https://bsky.app/profile/trey.io/post/3n2ri7dui452b)

----
**🕒 21:01 👤 @trey.io (Trey Hunner)**
💬 But it's not often that we care about the order of a dictionary.

When you're about to sort a dictionary, ask yourself: do I really need to sort this? And if I don't need key lookups, would a list of tuples be more suitable than a dictionary?
