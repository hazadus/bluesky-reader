**🕒 22:45 👤 @trey.io (Trey Hunner)**
💬 We can write this:

if wavelength < 455:
    color = "Violet"
elif wavelength < 492:
    color = "Blue"
elif wavelength < 577:
    color = "Green"
else:
    color = "Other"

Each "elif" removes a level of nesting, so the conditions read as one flat chain of checks instead of an indented staircase.
