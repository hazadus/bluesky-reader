💬 Python Tip #312 (of 365):

Use the "utf-8-sig" encoding for CSV files. 🧵

Many CSV files start with an invisible byte order mark (BOM).

When read as "utf-8", the first column name starts with a UTF-8 BOM character:

>>> rows[0]
{'\ufeffdate': '2026-10-01', 'kwh': '12.5'}

**🕒 00:48 👤 @trey.io (Trey Hunner)**
💬 Why do some CSV files have BOMs?

Well, Excel on Windows assumes a CSV file uses a legacy Windows encoding (like cp1252) unless it starts with a BOM. So lots of software adds a BOM to CSV exports, and Excel's own "CSV UTF-8" save option writes one.
