**🕒 18:04 👤 @trey.io (Trey Hunner)**
💬 Python Tip #303 (of 365):

Remember that strings are iterables of strings. 🧵

Python doesn't have a character type, which usually makes things easier.

If name is a string, name[0] returns a string, and strings have a lower method:

>>> name = "Ada"
>>> name[0].lower()
'a'

#Python #DailyPythonTip

**🕒 18:04 👤 @trey.io (Trey Hunner)**
💬 But it can also complicate things.

Passing join one string instead of a list of strings doesn't raise an error:

>>> " ".join(["I", "use", "Python"])
'I use Python'
>>> " ".join("I use Python")
'I   u s e   P y t h o n'

A string is an iterable of strings, so join happily joined each character.
