**🕒 05:44 👤 @trey.io (Trey Hunner)**
💬 Python Tip #313 (of 365):

Don't use match-case as a switch statement. 🧵

Python's match statement is for STRUCTURAL PATTERN MATCHING.

If you just need to check for specific values, an "if" statement is simpler.

#Python #DailyPythonTip

[Открыть пост](https://bsky.app/profile/trey.io/post/3mzwqd56umt2g)

----
**🕒 05:44 👤 @trey.io (Trey Hunner)**
💬 Do this:
if day in ("saturday", "sunday"):
    return "weekend"
else:
    return "weekday"

Not this:
match day:
    case "saturday" | "sunday":
        return "weekend"
    case _:
        return "weekday"

The match version adds indentation without using the "structural" part of pattern matching.
