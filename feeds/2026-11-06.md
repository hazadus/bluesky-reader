**🕒 04:43 👤 @trey.io (Trey Hunner)**
💬 Python Tip #309 (of 365):

Match dictionaries by their keys with match-case. 🧵

It's handy for JSON from an API: does a response have an error key, or a type key with a specific value?

Without match, that's an if-elif chain of "in" checks, key lookups, and equality checks.

#Python #DailyPythonTip

[Открыть пост](https://bsky.app/profile/trey.io/post/3mzml2wrmjm24)

----
**🕒 04:43 👤 @trey.io (Trey Hunner)**
💬 response = {"type": "rectangle", "width": 3, "height": 4}
match response:
    case {"type": kind}:
        print(f"Object is {kind}")
    case {"error": message}:
        print(f"Error: {message}")

Each case checks for specific keys (extra keys are ignored) and captures their values into variables.

**🕒 04:43 👤 @trey.io (Trey Hunner)**

match response:

    case {"type": "rectangle", "width": w, "height": h}:
        print(f"Rectangle {w}x{h}")
