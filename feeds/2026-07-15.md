**🕒 18:06 👤 @trey.io (Trey Hunner)**
💬 Python Tip #196 (of 365):

Manage your virtual environments with uv 🧵

You can get the speed of uv while still using venvs and pip the way you always have.

Instead of "python3.14 -m venv .venv", use "uv venv -p 3.14"

Instead of "pip install" use "uv pip install"

#Python #DailyPythonTip

[Открыть пост](https://bsky.app/profile/trey.io/post/3mqpcqnsaix22)

----
**🕒 18:06 👤 @trey.io (Trey Hunner)**
💬 But... why?

Speed!

Using "uv pip install" is often MUCH faster than using "pip install".

Also, if you have a "python-version" file or a pyproject.toml file that notes your project's Python version, "uv venv" will auto-select the correct Python version for you.

But it's mostly about speed.

[Открыть пост](https://bsky.app/profile/trey.io/post/3mqpcqp344p22)

----
**🕒 18:06 👤 @trey.io (Trey Hunner)**
💬 It's worth noting that "uv venv" does NOT add a pip command to the virtual environment it makes... at least not by default.

If you really want to be able to run pip from inside your virtual environment and not just "uv pip", pass the "--seed" flag:

uv venv --seed

That'll add a "pip" command also.
