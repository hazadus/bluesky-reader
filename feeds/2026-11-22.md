**🕒 21:01 👤 @trey.io (Trey Hunner)**
💬 Python Tip #326 (of 365):

When you don't care about a dictionary's values, use a set instead. 🧵

Finding yourself making a dictionary where the values are the same as the keys?

color_options = {"purple": "purple", "blue": "blue", "green": "green"}

#Python #DailyPythonTip

[Открыть пост](https://bsky.app/profile/trey.io/post/3n2wj6ftt2n2b)

----
**🕒 21:01 👤 @trey.io (Trey Hunner)**
💬 Or maybe you simply don't care about the values, so you've set them all to None?

color_options = {"purple": None, "blue": None, "green": None}

In either case, you could probably use a set instead:

color_options = {"purple", "blue", "green"}

[Открыть пост](https://bsky.app/profile/trey.io/post/3n2wj6fwg6h2e)

----
**🕒 21:01 👤 @trey.io (Trey Hunner)**
💬 There's one big exception to this tip: if you need to maintain the insertion order of your items, you need a dictionary.

Sets are unordered, but dictionaries maintain the insertion order of their items (see tip #323).

So if you don't care about your dictionary's values or its order, use a set.
