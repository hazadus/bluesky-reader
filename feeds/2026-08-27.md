**🕒 04:46 👤 @trey.io (Trey Hunner)**
💬 Implement __eq__ and ONE ordering method (like __lt__), then decorate with https://functools.total_ordering:

@total_ordering
class Version:
    ...
    def __eq__(self, other): ...
    def __lt__(self, other): ...

[Открыть пост](https://bsky.app/profile/trey.io/post/3mu224gtyb72l)

----
**🕒 04:46 👤 @trey.io (Trey Hunner)**
💬 That decorator writes the other three (>, =) for you:

>>> Version(3, 14, 2) > Version(3, 9, 0)
True
>>> Version(3, 14, 2) <= Version(3, 9, 0)
False

[Открыть пост](https://bsky.app/profile/trey.io/post/3mu224gwn2t2q)

----
**🕒 04:46 👤 @trey.io (Trey Hunner)**
💬 Or... if your class is a dataclass, just pass "order=True" (no __eq__ or __lt__ needed):

>>> @dataclass(order=True)
... class Version:
...     major: int
...     minor: int
...     patch: int
...
>>> Version(3, 14, 2) > Version(3, 9, 0)
True

Fields compare in order, like tuples do.
