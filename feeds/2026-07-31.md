💬 Python Tip #212 (of 365):

Use any() and all() to check a condition across every item in an iterable 🧵

This:
any_negative = False
for n in numbers:
    if n < 0:
        any_negative = True
        break

Can be rewritten as this:
any_negative = any(n < 0 for n in numbers)

**🕒 22:12 👤 @trey.io (Trey Hunner)**
💬 all() is the same, but checks whether the condition is true for EVERY item.

Anytime you see code like this:
all_good = True
for item in iterable:
    if not condition(item):
        all_good = False
        break

You can replace it with this:
all_good = all(condition(item) for item in iterable)

**🕒 22:12 👤 @trey.io (Trey Hunner)**
💬 One caveat: don't use any() or all() for checking containment.

This:
any(item == "something" for item in iterable)

Is the same as this:
"something" in iterable
