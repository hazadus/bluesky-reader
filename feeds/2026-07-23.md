💬 Python Tip #204 (of 365):

Generate unique identifiers with the uuid module 🧵

>>> import uuid
>>> uid = uuid.uuid4()
>>> uid
UUID('922a6cea-c3e9-473d-bf88-efb10793c931')
>>> str(uid)
'922a6cea-c3e9-473d-bf88-efb10793c931'

UUID stands for universally unique identifiers.

**🕒 18:04 👤 @trey.io (Trey Hunner)**
💬 The uuid module has functions for UUID version 1, 3, 4, 5, 6, 7, and 8 from RFC 4122/9562. Python 3.14 added 7 and 8.

The most useful UUID versions are versions 4 and 7 and you probably want one of those two.

UUID4 is the most common, but the sortability feature of UUID7 IDs can be very handy!

[Открыть пост](https://bsky.app/profile/trey.io/post/3mrdgef35de2j)

----
**🕒 18:04 👤 @trey.io (Trey Hunner)**
💬 Both uuid4() and uuid7() generate UUIDs with cryptographically secure randomness.

uuid7()'s random IDs are prefixed with their generation timestamp, meaning they're orderable/sortable by their generation time.

If you'd rather not reveal the generation time of your UUID, you'll want UUID4.
