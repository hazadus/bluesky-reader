💬 Python Tip #330 (of 365):

Pass a default to max and min to handle empty iterables. 🧵

The max and min functions raise an exception when given nothing to compare:

>>> max([])
Traceback (most recent call last):
  ...
ValueError: max() iterable argument is empty

#Python #DailyPythonTip

[Открыть пост](https://bsky.app/profile/trey.io/post/3n3al34cr4r2s)

----
**🕒 21:02 👤 @trey.io (Trey Hunner)**
💬 You could catch that ValueError:
def numeric_range(numbers):
    try:
        return max(numbers) - min(numbers)
    except ValueError:
        return 0

But it's simpler to pass a default instead:
def numeric_range(numbers):
    return max(numbers, default=0) - min(numbers, default=0)
