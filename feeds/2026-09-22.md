**🕒 17:02 👤 @trey.io (Trey Hunner)**
💬 Reading a CSV file and need to skip the first row of headers?

Pass your file object (or csv.reader object) to the built-in next function:

headers = next(reader)

File objects keep track of your position within an open file, so the next time you read (or loop) you'll start up where you left off.

[Открыть пост](https://bsky.app/profile/trey.io/post/3mw4ped6fi624)

----
**🕒 17:02 👤 @trey.io (Trey Hunner)**
💬 For file objects, this:

line = next(file)

Is effectively the same thing as this:

for line in file:
    break

They both move the file position forward by one line.

[Открыть пост](https://bsky.app/profile/trey.io/post/3mw4pedaswt2y)

----
**🕒 17:02 👤 @trey.io (Trey Hunner)**
💬 But... don't files have a readline method for this?

line = file.readline()

They do! And it does essentially the same thing as this:

line = next(file)

I prefer the more general purpose approach of the next(...) function because it works on files, csv.reader objects, and any other iterator.

[Открыть пост](https://bsky.app/profile/trey.io/post/3mw4pedesz527)

----
**🕒 17:02 👤 @trey.io (Trey Hunner)**
💬 Files had a readline method years before they were iterators. I suspect that they would never have had a readline method added to them if they were iterators from the beginning.

The next time you want to move a file one line forward, use the next function.
