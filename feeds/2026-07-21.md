💬 Python Tip #202 (of 365):

When prompting the user to enter a password, use getpass 🧵

The getpass.getpass function prompts the user to enter a password and what the user types is completely hidden:

>>> from getpass import getpass
>>> password = getpass()

💬 You can customize the prompt by passing a string, just like the built-in input function... and in Python 3.14 and above you can also use echo_char to show masked characters as the user types:

>>> key = getpass("API key: ", echo_char="*")
API key: ******************
>>> key
