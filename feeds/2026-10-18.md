**🕒 18:02 👤 @trey.io (Trey Hunner)**
💬 Python Tip #291 (of 365):

Check regex matches with the walrus operator. 🧵

Do this:
if match := UNITS_RE‍.search(string):
    return match.groups()

Not this:
match = UNITS_RE‍.search(string)
if match:
    return match.groups()

#Python #DailyPythonTip

[Открыть пост](https://bsky.app/profile/trey.io/post/3my66t2bpmu2x)

----
**🕒 18:02 👤 @trey.io (Trey Hunner)**
💬 A regex search returns either a match object or None.

A match object is truthy and None is falsey, so "if match" checks whether we got a match object to work with.

The walrus operator (":=") lets us embed the match assignment INSIDE that "if" condition.
