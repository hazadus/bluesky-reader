💬 Python Tip #193 (of 365):

To compare iterables while ignoring order and duplication, use a set equality check. 🧵

Like this:

>>> set(iterable1) == set(iterable2)
True

Like all things set-related, this requires hashable items.

💬 Python Tip #194 (of 365):

Install Python with uv 🧵

I recommend using:

$ uv python install --default 3.14

Specifying "--default" will install symbolic links for python, python3, and python3.N (where N is the minor version number).

#Python #DailyPythonTip

[Открыть пост](https://bsky.app/profile/trey.io/post/3mqkbpj6e7q2w)

----
**🕒 18:04 👤 @trey.io (Trey Hunner)**
💬 Using uv to install Python makes it easy to upgrade subminor versions.

Just run:

$ uv python upgrade

If you have Python 3.14.4 installed after 3.14.5 is out, that "python upgrade" command will install it.

[Открыть пост](https://bsky.app/profile/trey.io/post/3mqkbpjf6k527)

----
**🕒 18:04 👤 @trey.io (Trey Hunner)**
💬 Note that older versions won't be purged automatically.

You can use this command to see all the versions uv has installed:

$ uv python list --only-installed --managed-python

And this command to uninstall an old version:

$ uv python uninstall 3.11.3

💬 Note that to install the latest Python versions, you'll want to make sure you keep uv up-to-date.

You use uv to update itself with:

$ uv self update
