💬 Python Tip #266 (of 365):

Reread a file with seek(0). 🧵

Try to .read() a file twice, and you'll get nothing the second time:

>>> f = open("my_file.txt")
>>> f‍.read()
'This is my file 👋\nThis is line 2\n'
>>> f‍.read()
''

#Python #DailyPythonTip

[Открыть пост](https://bsky.app/profile/trey.io/post/3mw77ucrz472e)

**🕒 17:02 👤 @trey.io (Trey Hunner)**
💬 Python keeps track of your position within a file as you read.

When you're at the end, another read returns an empty string.

The seek method changes that position. seek(0) moves back to the beginning.

>>> f‍.seek(0)
0
>>> f‍.read()
'This is my file 👋\nThis is line 2\n'

[Открыть пост](https://bsky.app/profile/trey.io/post/3mw77ud2ra22b)

----
**🕒 17:02 👤 @trey.io (Trey Hunner)**
💬 Two caveats:

1. seek positions are BYTE offsets. In text mode, seeking anywhere but 0 can land you mid-character, so seek(0) is pretty much the only seek you'll use on text files.

2. Rereading a file is rare. If you need the contents twice, it's often easier to just read them into a variable once.
