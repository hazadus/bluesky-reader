**🕒 18:04 👤 @trey.io (Trey Hunner)**
💬 Python Tip #200 (of 365):

Beta-test the latest Python version with uv 🧵

You can use uv to try out alpha, beta, and rc (release candidate) Python versions. It's easy to try out the latest Python version before it's released.

#Python #DailyPythonTip

[Открыть пост](https://bsky.app/profile/trey.io/post/3mqzeiocrb72o)

----
**🕒 18:04 👤 @trey.io (Trey Hunner)**
💬 You can use uv to install an alpha/beta/rc release just like you'd install any other version:

$ uv python install 3.15

Before 3.15.0-final is released, that command will install the latest alpha, beta, or release candidate.

After 3.15.0 is officially released, that'll install the latest version.

[Открыть пост](https://bsky.app/profile/trey.io/post/3mqzeioftwe2i)

----
**🕒 18:04 👤 @trey.io (Trey Hunner)**
💬 Note that you'll need to update uv to get access to the most recent Python releases.

I usually install the first alpha for each new version as soon as it's released and then I use these commands to install each subsequent alpha/beta/rc as it's released:

$ uv self update
$ uv python upgrade

[Открыть пост](https://bsky.app/profile/trey.io/post/3mqzeiojf4v22)

----
**🕒 18:04 👤 @trey.io (Trey Hunner)**
💬 If you just want to test whether a specific library works in a new Python version, you can run a Python shell with uvx in that version with that particular library installed.

For example, to test whether requests works on Python 3.15:

$ uvx --python 3.15 --with requests python
