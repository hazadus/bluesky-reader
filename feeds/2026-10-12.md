**🕒 18:02 👤 @trey.io (Trey Hunner)**
💬 You can pass help a function, a module, a class, or even an instance of a class:

>>> numbers = [2, 1, 3, 4]
>>> help(numbers)
Help on list object:

class list(object)
 |  list(iterable=(), /)
 ...

Passing a class (or instance) shows the class docstring plus documentation for every method.

**🕒 18:02 👤 @trey.io (Trey Hunner)**
💬 Pass a string to help to look up an operator or a keyword:

>>> help("**")
The power operator
******************
...

Not sure what you can look up? Ask help for "topics", "symbols", or "keywords".

**🕒 18:02 👤 @trey.io (Trey Hunner)**
💬 Once you're INSIDE the help pager (on Linux and Mac), you can use these keyboard shortcuts:

• Arrow keys (or j/k) to scroll
• / to search within the page
• q to quit

On Windows, Enter scrolls a line, Space scrolls half a screen, and q quits.
