**🕒 23:47 👤 @trey.io (Trey Hunner)**
💬 Python Tip #276 (of 365):

Make self positional-only when accepting "**kwargs". 🧵

This class accepts any keyword argument... except self:

class Namespace:
    def __init__(self, **kwargs):
        for name, value in kwargs.items():
            setattr(self, name, value)

#Python #DailyPythonTip

[Открыть пост](https://bsky.app/profile/trey.io/post/3mwz33xtlym2l)

----
**🕒 23:47 👤 @trey.io (Trey Hunner)**
💬 Python gets multiple values for self because self is ALWAYS specified for every method:

>>> space = Namespace(other=2, self=1)
TypeError: Namespace.__init__() got multiple values for argument 'self'

But we were trying to ADDITIONALLY specify self for capturing in our kwargs dictionary.

[Открыть пост](https://bsky.app/profile/trey.io/post/3mwz33xxsoe25)

----
**🕒 23:47 👤 @trey.io (Trey Hunner)**
💬 We can fix this by putting a / between self and "**kwargs", forcing self to be positional-only:

def __init__(self, /, **kwargs):

Now a self keyword argument is captured into our kwargs dictionary instead:

>>> space = Namespace(other=2, self=1)
>>> space.self
1
