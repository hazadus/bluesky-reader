**🕒 15:04 👤 @trey.io (Trey Hunner)**
💬 Python Tip #296 (of 365):

Always use functools.wraps when making a decorator. 🧵

A decorator REPLACES a decorated function with the function that was returned from calling the decorator.

#Python #DailyPythonTip

[Открыть пост](https://bsky.app/profile/trey.io/post/3mykhaa5zqa2u)

----
**🕒 15:04 👤 @trey.io (Trey Hunner)**
💬 from functools import wraps

def time_runs(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        start = perf_counter()
        return_value = func(*args, **kwargs)
        print(f"{func.__name__} ran in {perf_counter()-start} seconds")
        return return_value
    return wrapper

[Открыть пост](https://bsky.app/profile/trey.io/post/3mykhaaaqmc22)

----
**🕒 15:04 👤 @trey.io (Trey Hunner)**
💬 Without "@wraps(func)", help would show a function called wrapper that accepts any arguments and has no docstring:

>>> @time_runs
... def is_prime(number):
...     """Return True if number is prime."""
...
>>> help(is_prime)
Help on function wrapper in module __main__:

wrapper(*args, **kwargs)

[Открыть пост](https://bsky.app/profile/trey.io/post/3mykhabfkdy2k)

----
**🕒 15:04 👤 @trey.io (Trey Hunner)**
💬 functools.wraps borrows the name, signature, and docstring of the decorated function and updates the wrapper to match:

>>> help(is_prime)
Help on function is_prime in module __main__:

is_prime(number)
    Return True if number is prime.
