💬 Python Tip #208 (of 365):

Break up long boolean expressions. 🧵

To improve the readability of long conditions try to:

1. Wrap it in parentheses to break it up over multiple lines
2. Use variables to give names to each sub-expression
3. Use functions to name sub-expressions

#Python #DailyPythonTip

💬 Wrapping an expression in parentheses allows us to break it over multiple lines of code, thanks to implicit line continuation.

PEP 8 recommends starting each line with a Boolean operator, so it's easy to see how the sub-expressions are joined.

💬 Instead of this:

if user["verified"] and event["date"] > datetime.‍now() and not event["full"]:
    print("Here's the event signup form...")

We could do:

if (
    user["verified"]
    and event["date"] > datetime.‍now()
    and not event["full"]
):
    print("Here's the event signup form...")

**🕒 21:54 👤 @trey.io (Trey Hunner)**
💬 Instead of this:

if amount == 1:
    noun = "item"
else:
    noun = "items"

We can write this:

noun = "item" if amount == 1 else "items"

Note that the condition is in the MIDDLE. The first value is the "true" case and the last is the "false" case.

💬 I typically only use conditional expressions when they're short.

I do sometimes wrap them over multiple lines:

key = (
    data["id"]
    if data["type"] != "customer"
    else data["customer_id"]
