**🕒 18:04 👤 @trey.io (Trey Hunner)**
💬 Python Tip #242 (of 365):

Prefer isinstance over type for type checking. 🧵

Do this:
isinstance(value, int)

Not this:
type(value) == int

Unlike comparing with type(...), using isinstance respects inheritance.

#Python #DailyPythonTip

[Открыть пост](https://bsky.app/profile/trey.io/post/3mucy3dopsl2b)

----
**🕒 18:04 👤 @trey.io (Trey Hunner)**
💬 A "type(...) == ..." check fails for subclasses:

>>> from collections import Counter
>>> counts = Counter("hello")
>>> isinstance(counts, dict)
True
>>> type(counts) == dict
False

Checking with type means nobody can inherit from your class without breaking your type check.

**🕒 18:04 👤 @trey.io (Trey Hunner)**
💬 Need to check for multiple types at once? Pass a tuple to isinstance:

>>> isinstance(4.5, (int, float))
True
>>> isinstance("4.5", (int, float))
False

**🕒 18:04 👤 @trey.io (Trey Hunner)**
💬 Also note that the ABCs in collections‍.abc check BEHAVIOR, not inheritance so they can be used for "goose typing" (see tip #219).

>>> from collections‍.abc import Iterable
>>> isinstance("hello", Iterable)
True

That's how I'd recommend asking "is this object iterable?"
