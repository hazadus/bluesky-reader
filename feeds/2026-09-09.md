**🕒 22:51 👤 @trey.io (Trey Hunner)**
💬 Python doesn't have constants. There's no keyword that stops a variable from being reassigned:

>>> MAX_RETRIES = 5
>>> MAX_RETRIES = 10

The all-caps name is purely a convention. It's a signal to readers of our code meaning "this value isn't meant to change".

[Открыть пост](https://bsky.app/profile/trey.io/post/3mv4mtjas7p2k)

----
**🕒 22:52 👤 @trey.io (Trey Hunner)**
💬 Note that while PEP 8 recommends this convention and the standard library uses it (re.IGNORECASE, logging‍.INFO) plenty of code doesn't use this... like the math module, which defines pi, tau, and e in all lowercase.

ALL_CAPS can be a helpful hint to readers, but it's far from a rule.
