💬 The itertools module includes various combinatorics-oriented utilities:

from itertools import combinations, combinations_with_replacement, permutations, product

This joins tuples of characters into a comma-separated string:

def join(groups):
    return ", ".join("".join(g) for g in groups)

**🕒 02:53 👤 @trey.io (Trey Hunner)**
💬 Those 4 itertools functions make up pretty much every way to grab 2 items from an iterable.

If order doesn't matter (AB is the same as BA):

>>> join(combinations("ABC", 2))
'AB, AC, BC'

With repeats:

>>> join(combinations_with_replacement("ABC", 2))
'AA, AB, AC, BB, BC, CC'

**🕒 02:53 👤 @trey.io (Trey Hunner)**
💬 If order DOES matter:

>>> join(permutations("ABC", 2))
'AB, AC, BA, BC, CA, CB'

With repeats:

>>> join(product("ABC", repeat=2))
'AA, AB, AC, BA, BB, BC, CA, CB, CC'

Calling itertools.product with repeat basically does a loop within a loop over the same iterable twice.

**🕒 02:53 👤 @trey.io (Trey Hunner)**
💬 You can also use itertools.product with multiple iterables (basically a loop within a loop for each one):

>>> join(product("ABC", "1234"))
'A1, A2, A3, A4, B1, B2, B3, B4, C1, C2, C3, C4'

All of those tools return iterators, so you can loop lazily without storing a whole list in memory.

💬 Python Tip #207 (of 365):

Get fancy with your subprocess‍.run calls 🧵

When launching a subprocess, consider passing the keyword arguments capture_output, text, and check to subprocess‍.run.

#Python #DailyPythonTip

[Открыть пост](https://bsky.app/profile/trey.io/post/3mrl73lilvy24)

----
**🕒 20:15 👤 @trey.io (Trey Hunner)**
💬 Passing "capture_output=True" will cause stdout & stderr from the subprocess to be captured.

Passing "text=True" will ensure the captured output is decoded into strings (instead of left as raw bytes).

Passing "check=True" will raise an exception if the subprocess exited with an error code.
