💬 Python Tip #310 (of 365):

Match objects by their type and attributes with match-case. 🧵

A class pattern checks an object's type (like isinstance does) and the values of its attributes, capturing attributes into variables.

#Python #DailyPythonTip

[Открыть пост](https://bsky.app/profile/trey.io/post/3mzp2nhxeff2v)

**🕒 04:27 👤 @trey.io (Trey Hunner)**
💬 With a Point dataclass:
match point:
    case Point(x=0, y=0):
        print("At the origin")
    case Point(x=0, y=y):
        print(f"On the y-axis at {y}")
    case Point(x=x, y=y):
        print(f"At ({x}, {y})")

For Point(x=0, y=4), that prints "On the y-axis at 4".

**🕒 04:27 👤 @trey.io (Trey Hunner)**
💬 Class patterns can also be nested, which is particularly great for parsing Python code with the ast module:

match node:
    case ast‍.Call(func=ast‍.Name(id="sorted"), args=[iterable]):
        print(f"Sorting {ast.unparse(iterable)}")

**🕒 04:27 👤 @trey.io (Trey Hunner)**
💬 That case matches a Call object whose func attribute is a Name object whose id is "sorted".

That stores the expression passed to sorted(...) into "iterable".

If you find yourself in code full of isinstance and attribute checks, consider match-case.
